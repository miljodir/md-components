# Structure

To use the `Divider` css in `@miljodirektoratet/md-css` as a standalone, without the accompanying React component, please use the following HTML structure.

Class names in brackets [] are optional-/togglable-/decorator- or state dependant classes.

See [Storybook](https://miljodir.github.io/md-components) for examples and more info.

## HelpButton

```html
<hr class="md-divider [md-divder--primary, md-divder--secondary, md-divder--tertiary]" />
```
