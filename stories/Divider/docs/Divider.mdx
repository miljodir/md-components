

A component for divider. In addition to the properties presented here, the component accepts all standard attributes of a HTML HR element.

Dividers are used to create a visual separation between content. It is a simple horizontal line that spans the available width.

## Use a divider when:

- You want to create a clear division of content  
- Whitespace alone does not provide sufficient separation

## Avoid a divider when:
- Natural spacing or other visual elements provide sufficient separation  
- Too many divider elements create a cluttered visual appearance

## Guidelines

Dividers are used to break content into smaller parts, making it more organized and easier to read. They can also be used to separate content that is related to each other but should still have a visual distinction.
  
## Color

By default, the divider uses the color `--md-color-border-secondary`. If needed, `--md-color-border-tertiary`, `--md-color-border-primary`, or other colors can also be used to adjust visual weight, contrast, or context.
